---
name: create-branch-pr
description: Create a conventional branch, commit the current changes, push it, and open a pull request. Use when the user explicitly requests the complete branch-to-PR workflow.
---

Use `$create-branch` to create the branch, then `$create-pr` to inspect, commit, verify, push, and open the pull request. Stop and report clearly if either step cannot complete without additional authorization or credentials.
